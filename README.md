# 📱 Calculadora de IMC – React Native + TypeScript

Este projeto foi desenvolvido com o objetivo **educacional**, para praticar os conceitos fundamentais do **React Native** utilizando **TypeScript**, além de entender melhor a organização de telas, navegação e lógica de negócio em um app mobile.

---

## 🎯 Objetivo do Projeto

Criar uma aplicação simples que permita:

- Autenticação básica (login e registro)
- Cálculo do **IMC (Índice de Massa Corporal)**
- Exibição da classificação do IMC de forma clara e visual

O foco principal **não é backend**, e sim aprender **React Native na prática**.
